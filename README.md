# Interactive Task Board

A responsive Kanban board built with HTML, CSS, and vanilla JavaScript for the Lime Light internship assignment.


## Features

- Create tasks with a title, description, category, and priority.
- Move tasks between To Do, In Progress, and Completed, or delete them.
- Search by title and filter by category.
- Save tasks and theme preferences in localStorage.
- Colour-coded priorities and light/dark themes.
- Responsive layout for desktop, tablet, and mobile.

## Run locally

Clone the repository and serve its folder with a local server, such as VS Code Live Server. No build step or dependencies required.

Tasks are stored in the current browser and are not synced across devices.
